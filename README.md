# 🍳 CookCasting

Додаток для підбору рецептів у стилі Tinder + TikTok — брат [MovieCasting](https://github.com/zharoslaw31/MovieCasting). Рецепти кухонь усього світу, **повністю українською**. Працює на **Android та iPhone** (як сайт-застосунок), безкоштовний і без реєстрації.

**Відкрити:** https://zharoslaw31.github.io/CookCasting/

| Розділ | Що вміє |
|---|---|
| 🔥 **Кастинг** | Картки рецептів: свайп **вправо** — хочу приготувати, **вліво** — не цікаво, **вгору** — вже готував. Кнопка «скасувати», перемішування, клавіші ← → ↑ на комп’ютері. Режими **🎲 Уся база** і **✨ Для тебе** (підбір за улюбленими кухнями, категоріями й продуктами). |
| 🍳 **Що приготувати?** | Сніданок / основна страва / суп / десерт / закуска + скільки є часу + кухня (Європа, Азія, Близький Схід і Африка, Америка, Україна) + обмеження → 5 варіантів, кнопка «Обери за мене». |

## Звідки рецепти і як вони перекладені

Рецепти беруться з [TheMealDB](https://www.themealdb.com) — відкритої бази страв з усього світу (з фото й відео YouTube). Скрипт [`scripts/build-recipes.mjs`](scripts/build-recipes.mjs):

1. завантажує всю базу TheMealDB;
2. перекладає українською назви, інгредієнти, міри, кроки й теги. Кухні, категорії й кількасот найчастіших інгредієнтів перекладені вручну ([`scripts/glossary.mjs`](scripts/glossary.mjs)), решта — машинним перекладом з автоматичними виправленнями (борошно, а не «мука», вершки, а не «сливки» тощо);
3. переводить унції й фунти в грами, Фаренгейти в Цельсії, `tbsp`/`tsp`/`cup` у «ст. л.», «ч. л.», «скл.»;
4. зберігає готову базу в [`src/data/recipes.json`](src/data/recipes.json) — вона вбудована в додаток, тож пошук і рецепти працюють без інтернету й без жодних ключів.

Пам’ять перекладів ([`scripts/translations.json`](scripts/translations.json)) лежить у репозиторії, тож повторний запуск перекладає лише нові рецепти. Щоб виправити якийсь переклад — додайте рядок у `scripts/glossary.mjs`.

GitHub Actions (**Update recipes**) оновлює базу щопонеділка і після змін у скриптах; запустити вручну: **Actions → Update recipes → Run workflow**.

## 🌍 Світова база ∞ (безкінечні рецепти)

Коли вбудовані рецепти закінчуються, Кастинг підмішує рецепти зі [Spoonacular](https://spoonacular.com/food-api) (понад 360 000 страв) і одразу перекладає їх українською на пристрої: назву, інгредієнти, міри та кроки. Пошук теж уміє шукати у світовій базі: запит перекладається англійською, результати — українською. Рецепти з бібліотеки й списку покупок зберігаються на пристрої назавжди, а з решти тримаються останні 250.

Потрібен безкоштовний ключ Spoonacular (150 запитів на день): вставте його в *Профіль → Світова база ∞*. Ключ зберігається лише на вашому пристрої й не потрапляє в код сайту.

## 👤 Акаунт і синхронізація

Вхід за email і паролем, як у MovieCasting, і той самий акаунт. Обране, приготоване, оцінки, список покупок і холодильник зберігаються в хмарі й доступні на всіх пристроях. Без входу все зберігається лише на пристрої.

Налаштування (один раз):

1. У Supabase виконайте [`supabase/cook_libraries.sql`](supabase/cook_libraries.sql) (SQL Editor → Run).
2. У Supabase → Authentication → URL Configuration → Redirect URLs додайте `https://zharoslaw31.github.io/CookCasting/`.
3. У цьому репозиторії додайте секрети Actions `SUPABASE_URL` і `SUPABASE_ANON_KEY` (ті самі значення, що в MovieCasting) і перезапустіть «Publish website».

## 🌐 Встановити на телефон

- **iPhone (Safari):** кнопка «Поділитися» → «На початковий екран».
- **Android (Chrome):** меню ⋮ → «Додати на головний екран» / «Встановити додаток».

Кожна зміна в гілці `main` автоматично публікується (GitHub Actions → GitHub Pages) за 2–3 хвилини.

## Розробка

```bash
npm install
npx expo start            # Expo Go на телефоні або w — у браузері
node scripts/build-recipes.mjs   # оновити базу рецептів
```

APK для Android: `npx eas-cli@latest build -p android --profile preview`.

## Технології

Expo SDK 58 · React Native · TypeScript · Expo Router · TheMealDB · AsyncStorage (усі ваші дані зберігаються локально на пристрої).

```
src/
  app/(tabs)/index.tsx      Кастинг (свайпи)
  app/(tabs)/videos.tsx     Стрічка відеорецептів
  app/(tabs)/library.tsx    Бібліотека і список покупок
  app/(tabs)/profile.tsx    Профіль і статистика
  app/recipe/[id].tsx       Сторінка рецепту, режим готування
  app/tonight.tsx           «Що приготувати?»
  app/fridge.tsx            «Що є вдома»
  app/filters.tsx           Фільтри
  lib/recipes.ts            База, фільтри, пошук, смак
  lib/store.tsx             Стан і збереження
scripts/                    Збирання й переклад бази
```
